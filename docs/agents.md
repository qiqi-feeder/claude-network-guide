# 将教程作为 Skill 交给不同 Agent

**简体中文** | [English](en/agents.md) · [返回首页](../README.md)

仓库中的 `skills/claude-network-setup/` 是 Skill 包，包含入口 `SKILL.md`、教学参考、脚本和手机配置模板。Windows 和 iPhone 都有执行分支。安装时复制整个目录，不能只复制 `SKILL.md`。

## 两种用法

**支持 Skills 的 Agent：** 按所用产品的技能安装说明，将完整目录加入其技能位置或通过仓库安装功能选择此目录。不同 Agent 的发现机制、目录和调用语法可能不同，不存在通用安装命令。确认它能发现 `claude-network-setup` 后，使用产品支持的方式调用。

**不支持 Skills、但能读取仓库的 Agent：** 提供仓库地址或下载后的目录，让它读取入口并按需读取相对路径资源。若只能粘贴文本，就分阶段提供入口和相关参考；没有提供的资源不能假定已被读取。这是提示词使用方式，不等于已安装原生 Skill。

可直接发送：

```text
请读取本仓库 skills/claude-network-setup/SKILL.md，并按其中的逐步教学流程指导我。
先确认我的设备、客户端、已有 VPS 和当前进度，只问缺少的信息。
每次给一个可完成的小步骤，说明预期结果，根据我的反馈再推进。
先只读检查并给出方案，不安装或修改，等我授权后再执行。
不能操作我的设备时，给我菜单指引，不要声称已经配置成功。
不要索取聊天中的密码，不要把节点凭据或私人数据上传仓库。
```

手机用户可补充：“我使用 iPhone + Shadowrocket，已有 VPS，希望用社区黑名单并保留独立增强规则。”电脑用户可补充实际客户端和偏好。Agent 应尊重用户选择，而不是让手机一律采用 Windows 规则。

## 能做到什么

Agent 可以按进度讲解、检查脱敏配置、生成文件，并指导分流、DNS、WebRTC 和故障验收。只有获得相应工具、设备访问和授权时，才能代操作。普通对话 Agent 不能直接读取本机连接或操作 iPhone，截图也不能证明所有网络路径都已验证。

本包不绑定某个 Agent 的专用工具。已完成 Skill 格式、资源链接和脚本检查；尚未在所有 Agent 上逐一验证安装与端到端执行，使用前核对目标产品文档。英文使用者可要求用英文教学；底层 Skill 入口和部分参考目前仍为中文。
