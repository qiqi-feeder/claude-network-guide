# Contributing

[简体中文](../../CONTRIBUTING.md) | **English** · [Guide home](../../README.en.md)

Compatibility fixes, redacted reproductions, and official documentation updates are welcome. Include OS, Clash Verge, Mihomo, and server versions, expected behavior, the observed connection path, and a rollback procedure.

For IPv6, WeChat, or VPN changes, check both domestic apps and protected services. A green test label alone is insufficient. Do not submit credentials, private profiles, complete paid articles, or rules copied without permission. Third-party experience is not an official guarantee.

Run the checks in [Maintenance](maintaining.md) before submitting. Tests must not alter real networking, sign in, or send messages. Keep Chinese and English instructions aligned, especially commands, prices, and routing behavior.
