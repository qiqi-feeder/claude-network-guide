# 首次使用与账号检查

**简体中文** | [English](en/claude-first-run.md)

先完成网络验收，再访问 https://claude.ai/ 。按实际所在地与当前官方要求判断能否使用，固定海外出口不能改变资格。

## Google 账号地区

登录自己要检查的 Google 账号，打开 https://policies.google.com/country-association-form ，看正文中“账号与以下地区相关联”。下方表单是申请修改，不是当前查询结果。不需要为了查询点提交。

账号关联地区、Google Play 地区、付款资料地区、当前 IP 和真实所在地是不同概念。不要据此承诺 Claude 注册成功或无需验证。

## 登录与隐私

按官方页面使用自己的账号。验证码、密码与身份材料由用户自己在官方界面输入。首次欢迎页可能包含模型改进选项；由用户按隐私偏好决定是否允许聊天或编程内容用于训练，不将开关状态当作账号风控技巧。具体说明以当前页面为准。

若页面显示 account on hold，阅读页面的暂停时间与原因。暂停可能早于当前网络配置；建议使用真实信息请求官方复核，不能把换账号、清机器标识或购买他人已验证账号当作恢复步骤。

## 时区

只有用户要求时才改系统时区。UTC+8 表示比 UTC 快八小时；北京、新加坡和台北通常钟面相同，时区名称不同。洛杉矶有夏令时，不能硬编码永远相差十五小时。

语言、时区和设备信息可能被网页读取，但不等于 IP 泄漏，也没有本项目验证的“防封时区”。不为了制造某国身份指导虚假资料或伪装日常对话。

订阅、付款、身份认证走当前官方流程，不提供代过验证、虚假账单地址或多账号轮换规避额度。价格与套餐变化快，本教程不把社交媒体“养号天数”当作官方要求。
