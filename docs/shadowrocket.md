# iPhone：Shadowrocket 与自有 VPS

**简体中文** | [English](en/shadowrocket.md) · [返回首页](../README.md)

适用于已有 sing-box + VLESS Reality VPS 的手机。本文采用原教程推荐的 **Johnshall 黑名单＋去广告**，与本仓库 Windows 默认白名单不同：黑名单未命中流量直连；白名单未命中流量代理。增强配置是本项目补充，不是博主原版。

## 导入与选择配置

1. 在首页导入自己的 VLESS 节点，核对地址、端口、UUID、Reality 公钥、short-id、SNI 和 Vision。节点链接和二维码包含连接凭据，不要提交 GitHub。
2. 在「配置」页添加 [Johnshall 黑名单配置](https://raw.githubusercontent.com/Johnshall/Shadowrocket-ADBlock-Rules-Forever/release/sr_top500_banlist_ad.conf)，保留文件名 `sr_top500_banlist_ad.conf`。这不是首页的节点订阅。
3. 下载 [增强模板](../examples/shadowrocket-ai-extension.example.conf)，将所有 `MY-US-VPS` 替换为实际节点名称。示例使用简单英文名，避免 DNS 参数中的名称编码问题。
4. 导入增强文件并选中它，首页「全局路由」选择「配置」。增强文件通过 `include` 继承社区文件；只需一个使用中的勾选，基础文件留在本地，不用同时勾选。

电脑的本地文件链接不能直接在手机下载。可以用 iCloud Drive／文件 App 导入；也可以在小火箭「配置 → Wi-Fi 上传」打开页面，再用同一局域网的电脑浏览器访问它显示的地址，上传文件。不要把本地路径当成公共下载地址。

模板只含通用字段，没有节点凭据。它增加固定 AI 策略与代理 DNS，不复制整份社区名单。部署前备份现有配置；模板经过文本检查，仍需按下文实机验收。

## 自动更新和名单大小

保留基础配置的远程更新来源，在「设置 → 自动更新 → 配置」启用更新，并允许 iOS 后台刷新。导入文件不代表自动更新已经生效：手动更新一次，检查更新时间及编译结果。更新基础文件后，重新检查增强配置的最终规则。节点订阅的更新是另一项设置。

不要把自定义规则直接写入会被远程覆盖的基础文件；单独保留增强层。若来源更新后文件名或语法变化，应检查继承是否还有效。自动更新受 iOS 调度及网络影响，不是精确计时任务。

大名单可能增加首次下载、编译和内存开销，但文件大小不能单独解释微信上传缓慢；编译后的显示大小也不等于原始下载大小。先看实际连接和资源表现。

## DNS、IPv6 与 WebRTC 分开验收

| 检测项 | 如何理解 |
|---|---|
| HTTP 出口 | 核对需要代理的请求是否使用指定 VPS |
| DNS 出口 | 显示的可能是递归解析器，不必等于 VPS；还要确认保护域名的查询路径 |
| WebRTC／STUN UDP 出口 | 若显示本地运营商公网 IP，说明该次探测获知了国内出口；DNS 通过不能抵消它 |
| 中国直连 IPv4 | 黑名单允许直连的探测端点可能显示它；不能据此断言 Claude 主请求直连 |

候选地址（candidate）是 WebRTC 为建立连接收集的地址。候选只有 VPS IP，不足以证明国内 IP 泄漏；候选出现真实国内公网地址，则需排查。检测站的黄色提示和分数不是 Claude 官方风控结论。

模板的 `ipv6 = false` 是小火箭配置项，不是关闭 iPhone 全系统 IPv6，也不能证明不存在绕行。不要照搬 Windows 的 `IP-CIDR6,::/0,REJECT`，这可能误伤微信等应用。

若 WebRTC 出现国内公网地址，先关闭 Claude，再尝试「设置 → UDP → 禁用 STUN」，保持 UDP 转发开启，重连后用新页面复测。它可能影响通话或 P2P，不能代替所有 UDP 路径的验收。不要伪造 STUN 返回 IP 来换取绿灯。模板将不支持的 UDP 行为设为 `REJECT`，避免该项回退直连；仍需检查全局回退及其他策略。

## 验收清单与微信排障

- 「测试规则」中，`claude.ai` 应命中 `AI-US`；该组只有自己的 VPS，没有 `DIRECT`。同时在「数据」查看真实连接，不能只靠静态测试。
- 分别测试网页出口、DNS、WebRTC、IPv6，以及 Wi-Fi／蜂窝网络切换。测试记录要注明网络、配置名和时间。
- 关闭 Claude 后，临时模拟节点不可达，确认保护请求失败而不是直连；恢复节点后再开启 Claude。本项目尚未验证每个 iOS／小火箭版本的断线、休眠及切网行为。
- 微信上传慢时，在「数据」查看上传瞬间的目标域名／IP、命中规则和实际策略。直连慢就继续检查本地网络；代理慢才检查误分流和 VPS。不要直接放行整个微信进程或全部腾讯 ASN。
- App Store 可能涉及多个 Apple/CDN 域名，以实际连接命中规则为准，不能仅凭应用名称判断全部直连或代理。

**黑名单无法满足“任意网页、任意探测都永远看不到国内 IP”的目标。** 未收录流量允许直连是其设计。固定 AI 域名规则只保护匹配范围；更严格的需求需另设计隔离环境、完整路由和故障阻断，并实测。
