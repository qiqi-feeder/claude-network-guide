# 按实际路径排障

**简体中文** | [English](../../../docs/en/troubleshooting.md)

## 微信文字正常、图片发不出

先读内核连接和日志，不默认关闭 TUN 或严格路由。若国内 IPv6 TCP/UDP 地址在 443、8000 等端口反复命中 `IPCIDR(::/0) REJECT`，检查并移除全局 IPv6 拒绝规则，让它们按国内 IP 规则直连。IPv6 仍进入 TUN，不为修微信全局放行海外连接。

规则切换后微信可能缓存失败状态，由用户从托盘完全退出后重开并重试。未经明确授权不能替用户向联系人发送图片；收到用户实际确认后才能写“已恢复”。同时复测 Claude 路由和代理节点故障行为。

若连接实际走 VPS，检查域名白名单、进程识别与腾讯海外节点。不要直接放行全部腾讯 ASN 或整个微信进程而不说明范围，它们可能扩大直连边界。先做最小适用修复，记录来源与回滚。

## DNS 标签异常

先看检测使用的域名、解析器归属与查询路径。国内域名使用国内 DNS 是分流预期；Claude 域名意外走国内解析器才是需要修复的配置路径。浏览器安全 DNS 与其他代理扩展可能改变行为，但先测再归因。

## WebRTC 显示 candidate leak

候选地址是 VPS IP，说明本次候选使用代理出口；不是中国公网 IP 泄漏。国内 STUN 测试可能因分流显示国内地址，体现允许直连的边界。一次成功不能代表所有 STUN 服务器或未来页面依赖。

## 403、账号暂停或登录异常

命令行 403 不等于浏览器登录一定失败。`account on hold` 是服务端账号状态，不靠清缓存或换时区解除；引导真实申诉，不声称网络调整能恢复账号。

## 时区与语言

UTC+8 时区之间切换一般不改变钟面时间，但会改变浏览器暴露的时区名称。它不是网络修复，也不是使用资格证明。只有用户要求时修改，说明对日历与软件的影响。
