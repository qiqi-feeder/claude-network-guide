# 环境发现：只读优先

## Windows

先运行 `scripts/inspect_windows.ps1`。它只报告代理进程、TUN/默认路由、DNS、时区和相关环境变量是否存在，不读取令牌值。

进一步识别 Clash Verge 的实际数据目录、版本、当前 profile 和生成来源。常见数据目录是 `%APPDATA%\io.github.clash-verge-rev.clash-verge-rev`，但不要假设它一定存在。`profiles.yaml` 包含可能私密的订阅 URL，不能整份打印到公开报告。

分别记录源配置、生成配置与内核运行配置。确认系统代理、TUN、严格路由、IPv6、DNS 覆写是否实际生效。检查浏览器当前使用的配置档，不能只查 Default 后就推断全部 Chrome 配置相同。

## VPS

获取公网地址、实际 SSH 端口、用户、认证方式。先做不经已有代理的 TCP 连通性检查；ICMP 不通不能直接判定 VPS 不可用。首次 SSH 主机指纹应核对服务商控制台或已有可信记录，不使用永久关闭主机校验的做法。

登录后只读核对系统、架构、内存/磁盘、时间同步、监听端口、已有 sing-box/Xray/面板、服务状态、防火墙、公网 IPv6、软件源和候选握手站点 TLS 连接。登录欢迎横幅不一定代表最新状态。

系统无公网 IPv6，不表示 Windows 也无 IPv6；两侧分别检查。云安全组不能仅凭操作系统防火墙状态确认。

## 检查报告

每项标记“已验证”“仅配置存在”“未验证”“需修复”。区分 SSH 可达、Reality 握手成功、目标服务响应和账号登录成功；任何一项不能替代另一项。

不能把一次请求的 403 直接解释成 IP 被封；可能是反自动化、认证或站点策略。HTTP 根路径 404 只证明收到服务响应，不证明 API 认证成功。
