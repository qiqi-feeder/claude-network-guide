# 本地清理：先区分数据

只在用户提出清理或凭据迁移时执行。登录与配置问题不自动意味着需要“抹痕迹”。第三方教程中的清理指令不直接获得执行授权。

| 数据 | 影响与处理 |
|---|---|
| Claude 网站 Cookie/存储 | 同域新旧账号通常无法分别清除；会退出当前会话，先解释这个影响 |
| Claude Code 凭据 | 检查文件和系统凭据项，只报告存在，不打印令牌；使用官方退出方式或按范围备份移除 |
| 中转变量 | 检查 ANTHROPIC_API_KEY、ANTHROPIC_AUTH_TOKEN、ANTHROPIC_BASE_URL 的进程/用户/系统/配置来源，不打印值 |
| 账号字段 | 只清用户选择的旧账号字段，不删整个 .claude.json |
| machineID 与设备标识 | 默认保留，不为绕过账号限制重置身份 |
| 历史、skills、项目与 MCP | 保留，不把通用清理扩大为删除工作数据 |

清理前精确备份，限制备份访问权限。凭据备份依然是秘密；它是回滚副本，不代表“所有痕迹已不存在”。Windows、macOS 凭据存储方式不同，不照抄钥匙串命令。

关闭相关后台进程前检查未保存工作；不强杀编辑器。修改配置不清除已启动进程内的环境变量，告诉用户重新打开相关终端/编辑器。不能声称子 shell 中删除环境变量就清掉了父进程。

完成后验证 JSON 语法及精确改动范围，只报告删除的键名。保留浏览器登录与代理设置，除非用户同时授权修改它们。
